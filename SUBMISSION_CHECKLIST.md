# Submission Checklist

- [ ] Copy `.env.example` to `.env`; add valid OMDb and Firebase settings.
- [ ] `npm install`
- [ ] `npm run dev`
- [ ] Search at least two different movie titles.
- [ ] Register, sign out, and sign in.
- [ ] Add/remove favorites and verify persistence after refresh.
- [ ] Confirm signed-out favorite action redirects to Auth.
- [ ] Apply Firebase rules and test two-account isolation.
- [ ] `npm run lint`
- [ ] `npm run build`
- [ ] Inspect responsive layout and keyboard focus.
- [ ] Push this project to its own GitHub repository.
- [ ] Deploy the Vite app to Vercel.
- [ ] Add real GitHub and Vercel URLs to your submission.
- [ ] Review `AI_PROMPTS.md`, `AI_USAGE.md`, and `MANUAL_IMPROVEMENTS.md`.
