# How AI Assisted

AI assisted with converting the assignment into a checklist, suggesting the folder architecture, drafting typed OMDb service functions, building reusable React UI, sketching Firebase auth/favorites flows, writing responsive CSS, and preparing setup documentation.

## Human responsibilities
Before submission, the developer must add their own OMDb/Firebase configuration, run and test the app locally, test account creation/login/logout, verify favorites persist across refresh, test the redirect for signed-out users, apply and verify Firebase rules using two accounts, inspect responsive layouts, run lint/build, and review all generated code.

AI-generated code may contain mistakes. The developer remains responsible for validating functionality, security, and final claims.
